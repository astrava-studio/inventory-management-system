# Project Guidelines & Preferences

## Figma Integration
- **Proactive Usage**: Whenever working on UI components, layouts, design tokens, workflows, or diagrams, leverage Figma integration and Figma skills.
- **Design-to-Code**: Inspect and align code with Figma components and designs.
- **Diagrams & Specs**: Use FigJam / Figma diagrams when documenting system architectures, user flows, and state machines.

## Google Stitch Integration
- **Proactive Usage**: Use Stitch MCP tools and skills for generating screens, managing design systems (`DESIGN.md`), and converting Stitch designs to modular React components.
- **Bi-directional Sync**: Convert frontend code to Stitch designs (`code-to-design`) and extract design systems when needed.

## Framer / Framer Motion
- **Animations & Micro-interactions**: Use `framer-motion` for page transitions, component animations, layout animations, gestures, and interactive UI polish.
